# GGZONE — Gaming Zone Management System

A web-based Gaming Zone Management System developed to manage games, gaming stations, and bookings. The project provides an organized interface for users to explore games and manage gaming zone activities.

## 1. Project Features

- Display available games and gaming stations.
- User registration and login.
- Gaming station booking.
- Game listings and descriptions.
- Admin panel for management.
- MySQL database integration.
- Responsive user interface.

## 2. Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL
- **Tools:** Visual Studio Code, Git, and GitHub

## 3. Project Structure

- `app.py` — Main Flask application.
- `templates/` — HTML templates.
- `static/` — CSS, JavaScript, and images.
- `schema.sql` — Database structure and queries.
- `requirements.txt` — Python dependencies.

*The filenames above should match the actual files in your project.*

## 4. Installation and Setup

1. Install Python and MySQL.
2. Clone or download this repository.
3. Install the required Python packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Create the `gaming_zone` database in MySQL and import the provided SQL schema.
5. Configure the database connection using your local settings.
6. Start the Flask application:

   ```bash
   python app.py
   ```

7. Open `http://127.0.0.1:5000/` in your browser.

## 5. Project Objective

The main objective is to simplify gaming zone operations by providing a centralized system for game listings, station information, and bookings.
